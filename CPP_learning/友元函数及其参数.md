## 问   
下列运算符重载函数中，属于友元函数的是（）
A.Base operator+(Base);
B.Base operator--(Base);
C.Base operator&&(Base, Base);
D.Base operator++(Base,int);    

## 答  
你的答案 **AD** 中：**D 对，A 错；B 你漏了，C 也对**。正确答案确实是 **BCD**。  
但官方解析里有一处明显不准确：**B 不是“后置递减”，B 是前置递减的友元形式**。后置 `--` 的友元形式需要两个参数 `(Base&, int)`，不是 `(Base)`。

---

## 1. 核心判定规则

成员函数重载运算符时，第一个操作数是对象自己，也就是隐含的 `this`，所以**显式参数比操作数少一个**。友元函数没有 `this`，**所有操作数都要显式列出来**。

| 表达式 | 成员函数形式 | 友元函数形式 |
|---|---|---|
| `a + b` | `a.operator+(b)`，显式 1 个参数 | `operator+(a, b)`，显式 2 个参数 |
| `a && b` | `a.operator&&(b)`，显式 1 个参数 | `operator&&(a, b)`，显式 2 个参数 |
| `--a` 前置 | `a.operator--()`，显式 0 个参数 | `operator--(a)`，显式 1 个参数 |
| `a--` 后置 | `a.operator--(0)`，显式 1 个 `int` | `operator--(a, 0)`，显式 2 个参数 |
| `++a` 前置 | `a.operator++()`，显式 0 个参数 | `operator++(a)`，显式 1 个参数 |
| `a++` 后置 | `a.operator++(0)`，显式 1 个 `int` | `operator++(a, 0)`，显式 2 个参数 |

后置 `++/--` 里的 `int` 是一个**哑元参数**，只用来和前置形式区分，调用时编译器自动传 `0`。

---

## 2. 逐项分析

题目选项：

```cpp
A  Base operator+(Base);
B  Base operator--(Base);
C  Base operator&&(Base, Base);
D  Base operator++(Base, int);
```

### A：`Base operator+(Base);`

`+` 通常按双目加法理解。

- 成员形式：`Base operator+(Base);` 只有一个显式参数，合法，表示 `a + b` 调 `a.operator+(b)`。
- 友元双目形式：应是 `Base operator+(Base, Base);`，需要两个显式参数。

所以 A 按题目语境是**成员函数形式**，不是友元。

> 严格说，如果写成 `friend Base operator+(Base);`，它也可以是一元正号 `+a` 的友元重载。但题目没有 `friend`，且默认 `+` 为双目加法，所以 A 按成员函数判断。

### B：`Base operator--(Base);`

`--` 有两种：

- 前置 `--a`：成员形式 `Base operator--();` 显式 0 参；友元形式 `operator--(Base);` 显式 1 参。
- 后置 `a--`：成员形式 `Base operator--(int);` 显式 1 个 `int`；友元形式 `operator--(Base, int);` 显式 2 参。

B 是 `Base operator--(Base);`，一个 `Base` 参数：

- 不可能是成员前置 `--`，因为成员前置应 0 参；
- 不可能是成员后置 `--`，因为成员后置应参数为 `int`；
- 所以它对应的是**友元前置 `--`** 的形式，即 `operator--(a)`。

因此 B 属于友元形式。  
**官方解析说 B 是“后置递减运算符的形式”是错的；B 是前置递减的友元形式。** 实际编码时一般写成：

```cpp
friend Base& operator--(Base&);
```

题目里参数没写引用，是考试简化。

### C：`Base operator&&(Base, Base);`

`&&` 是双目运算符。

- 成员形式应只有一个显式参数：`Base operator&&(Base);`
- 友元形式需要两个显式参数：`operator&&(a, b)`。

C 有两个参数，所以是**友元函数形式**。

> 实际中一般不重载 `&&`，因为会失去短路求值特性；这里只考形式。

### D：`Base operator++(Base, int);`

这是后置 `++` 的友元形式：

```cpp
a++  ->  operator++(a, 0)
```

- 成员后置 `++` 应写成 `Base operator++(int);`，只有一个 `int`；
- 友元后置 `++` 写成 `operator++(Base, int)`，两个参数。

D 有两个参数 `(Base, int)`，所以是**友元函数形式**。实际一般写成：

```cpp
friend Base operator++(Base&, int);
```

## 3. 为什么你选 A 会错

你可能把 A 看成了“有一个参数，所以是友元”。但判断不能只看“有没有参数”，还要看这个运算符是几元运算符、是不是后置 `++/--`。

- A 的 `operator+(Base)`：对双目 `+` 来说，一个显式参数正是**成员形式**；友元双目 `+` 应该两个参数。
- B 的 `operator--(Base)`：对前置 `--` 来说，一个显式参数是**友元形式**；成员前置 `--` 应该无参。
- D 的 `operator++(Base, int)`：两个参数，是**后置 `++` 的友元形式**。

所以：
```text
A：成员
B：友元
C：友元
D：友元
```

答案 BCD。

---

## 4. 更深一点：成员和友元到底差在哪

成员函数形式：

```cpp
class Base {
public:
    Base operator+(const Base& rhs);  // 成员，a+b -> a.operator+(b)
};
```

友元函数形式：

```cpp
class Base {
    friend Base operator+(const Base& lhs, const Base& rhs); // 友元，a+b -> operator+(a,b)
};
```

关键区别：

1. **成员函数有隐含的 `this`**，所以显式参数少一个。
2. **友元函数不是成员函数**，只是被类授予访问私有成员的权限，本质上是普通函数。
3. 成员形式的左操作数必须是类对象，且不能对左操作数做隐式转换；友元形式两个操作数都可以参与隐式转换，所以像 `2 + obj` 这种对称场景更适合友元/非成员。
4. 后置 `++/--` 用 `int` 哑元区分前置；不要把它误认为“后置只要一个参数就是友元”，后置友元需要两个参数。

---

## 5. 还要注意题目本身不严谨

严格 C++ 中，单看：

```cpp
Base operator+(Base);
```

并不能绝对判断它是成员还是友元，必须看声明位置和有没有 `friend`：

```cpp
class Base {
    Base operator+(Base);              // 成员
    friend Base operator+(Base);       // 友元（一元正号）
};
```

题目省略了 `friend` 和类作用域，是按“参数形式”让你判断。考试逻辑下选 **BCD**。但你要知道：**B 是前置 `--` 的友元形式，不是后置；D 才是后置 `++` 的友元形式。**
