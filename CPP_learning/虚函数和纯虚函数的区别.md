## 问   
虚函数和纯虚函数有什么区别？   

## 答   
**核心结论**：虚函数有实现，子类可重写可不重写；纯虚函数强制子类实现，含纯虚函数的类是抽象类，不能直接实例化。

| 对比项 | 虚函数 | 纯虚函数 |
|---|---|---|
| 声明 | `virtual void f();` | `virtual void f() = 0;` |
| 有没有函数体 | 必须有 | 通常没有，也可以有（很少见） |
| 所在类能否实例化 | 能 | 不能（抽象类） |
| 子类是否必须重写 | 不必须 | 必须，否则子类也是抽象类 |
| 用途 | 提供默认行为，允许子类覆盖 | 定义接口，强制子类实现 |
| 多态 | 支持 | 支持 |

**例子：**

```cpp
// 虚函数：有默认实现
class Base {
public:
    virtual void hello() { qDebug() << "Base"; }
};

class Derived : public Base {
public:
    void hello() override { qDebug() << "Derived"; }  // 可写可不写
};

// 纯虚函数：定义接口
class ICloudStorage {
public:
    virtual ~ICloudStorage() = default;
    virtual bool login(const QString&, const QString&) = 0;   // 必须实现
    virtual QList<CloudBucket> listBuckets() = 0;              // 必须实现
};

class LocalStorage : public ICloudStorage {
public:
    bool login(...) override { ... }        // 必须实现
    QList<CloudBucket> listBuckets() override { ... }  // 必须实现
};
```

**对应你的代码：**

- `ICloudStorage::login` / `listBuckets` 是纯虚 → `LocalStorage` 必须实现，否则 `LocalStorage` 也不能 `new`。
- `QAbstractListModel` 的 `rowCount` / `data` 是纯虚 → `BucketModel` 必须实现，否则 `BucketModel` 是抽象类。
- `QAbstractListModel` 已经帮你实现了 `columnCount`（返回 1），所以 `BucketModel` 不用写。

**顺带提醒**：你的 `ICloudStorage` 缺了虚析构函数，应该加一行：

```cpp
virtual ~ICloudStorage() = default;
```

否则通过 `ICloudStorage*` 删除 `LocalStorage` 对象时，行为未定义。
